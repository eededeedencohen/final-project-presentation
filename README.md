# Smart Cart - מצגת אינטראקטיבית (React + Vite)

שחזור **אחד-לאחד** של המצגת המקורית (`canva presentation.pptx`) כאפליקציית ווב:
כל 20 השקפים עם אותם מיקומים, טקסטים, גדלים, פונטים והתמונות המקוריות -
כשהרקעים והצבעים הכלליים הם מהעיצוב הממותג של הגרסה הזו (רקע בהיר עם מוטיב מעגלים חשמליים).

## הרצה

```bash
npm install      # פעם ראשונה בלבד
npm run dev      # שרת פיתוח - נפתח בדפדפן
npm run build    # בניית גרסה סטטית לתיקיית dist/
npm run preview  # תצוגה של הגרסה הבנויה
```

## שליטה במצגת

| מקש                    | פעולה                                |
| ---------------------- | ------------------------------------ |
| `→` / `רווח` / `Enter` | השקף הבא                             |
| `←` / `Backspace`      | השקף הקודם                           |
| `G` / `Esc`            | מבט-על של כל השקפים (קליק קופץ לשקף) |
| `F`                    | מסך מלא                              |
| `Home` / `End`         | קפיצה להתחלה / לסוף                  |
| `?`                    | חלון קיצורי מקלדת                    |

יש גם החלקה במסך מגע, וקפיצה לשקף דרך ה-URL: `#/7`.

## מבנה הפרויקט

```
src/
├── index.css                  ← טוקנים גלובליים: צבעים, פונטים, צללים
├── App.css                    ← CSS כללי: אנימציות כניסה (.fx), בסיס שקף (.pslide)
├── slides/
│   ├── index.jsx              ← רישום השקפים - הסדר כאן = סדר המצגת
│   └── p01/ ... p20/
│       ├── SlideXX.jsx        ← קומפוננטת השקף (נאמנה למקור)
│       └── styles.css         ← כל המיקומים/גדלים/פונטים של השקף הזה
├── slides-designed/           ← (בונוס) גרסת עיצוב-מחדש חופשית שנבנתה קודם.
│                                 לא בשימוש; אפשר להחליף אליה דרך slides/index.jsx
├── components/
│   ├── Deck/                  ← מנוע המצגת (ניווט, התקדמות, מבט-על, מסך מלא)
│   └── CircuitBackground/     ← רקע מסילות המעגל החשמלי
└── assets/media/              ← כל התמונות המקוריות שחולצו מה-PPTX

tools/                         ← כלי החילוץ (לשחזור/עדכון מה-PPTX)
├── extract-pptx.js            ← PPTX (מחולץ כ-zip) → slides.json
├── generate-slides.js         ← slides.json → קומפוננטות React
└── slides.json                ← נתוני 20 השקפים שחולצו
```

## איך עורכים

- **טקסט של שקף** - פותחים את `src/slides/pXX/SlideXX.jsx`; הטקסטים מופיעים כ-JSX רגיל.
- **מיקום/גודל/צבע של אלמנט** - ב-`styles.css` של אותו שקף. כל אלמנט הוא מחלקה
  `pXX-eN` עם `left/top/width/height` בפיקסלים על במה של 1920×1080.
- **סדר / הסרת שקפים** - עורכים את המערך ב-`src/slides/index.jsx`.
- **רקע כללי** - המחלקות `.pslide` ו-`.pslide-dark` ב-`src/App.css`, והצבעים ב-`src/index.css`.
- **השהיות אנימציית כניסה** - כל אלמנט נכנס עם `fx fx-fade` ו-`--d` (מילישניות) ב-JSX.

## פונטים

הפונטים המקוריים של המצגת מותקנים כחבילות npm ונטענים ב-`src/main.jsx`:
Open Sans (כולל עברית), Inter (תחליף ל-TT Norms/Canva Sans), Montserrat, League Spartan,
ו-Heebo כגיבוי לעברית. הכול ארוז בבילד - עובד גם בלי אינטרנט.

## שחזור מה-PPTX (אם רוצים לחולל מחדש)

```bash
# 1. לחלץ את ה-pptx (זה קובץ zip) לתיקייה כלשהי
# 2. לחלץ נתונים:
node tools/extract-pptx.js <תיקיית-החילוץ> tools/slides.json
# 3. לחולל קומפוננטות (דורס את src/slides/pXX):
node tools/generate-slides.js tools/slides.json src
```

(דורש `npm i fast-xml-parser` זמנית.)
